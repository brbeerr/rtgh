# MeshVPN Desktop (Windows/Linux)

Desktop version of MeshVPN - Electron app with same functionality as Android version.

## Features

- Create/join private rooms with 8-char keys
- Real-time chat (SSE)
- Members list with virtual IPs
- 7 free built-in servers
- Builds as .exe (Windows) and AppImage (Linux)

## Dev

```bash
cd mesh-vpn
npm install
npm start
```

## Build

```bash
npm run build        # Windows .exe
npm run build-all    # Windows + Linux
```
