# Slot Game Demo

Прототип веб-слот-игры с Canvas рендерингом и mock-сервером.

## Архитектура

```
┌─────────────────────────────────────────────┐
│  Клиент (браузер)                           │
│  ┌─────────┐  ┌──────────┐  ┌───────────┐  │
│  │ Loader  │→ │ Game.js  │→ │  Canvas   │  │
│  │(progress)│  │ (движок) │  │(рендеринг)│  │
│  └─────────┘  └────┬─────┘  └───────────┘  │
│                     │ fetch()                │
└─────────────────────┼───────────────────────┘
                      │
┌─────────────────────┼───────────────────────┐
│  Сервер (Express)   │                       │
│  ┌──────────────────▼────────────────────┐  │
│  │  /api/game/init  - создание сессии    │  │
│  │  /api/game/spin  - спин (RNG)         │  │
│  │  /api/game/balance - баланс           │  │
│  └───────────────────────────────────────┘  │
└─────────────────────────────────────────────┘
```

## Запуск

```bash
cd slot-game
npm install
npm start
```

Открыть: http://localhost:3000

## Что реализовано

- Canvas рендеринг символов
- Анимация вращения барабанов с easing
- 20 линий выплат
- Mock-сервер с RNG и расчётом выигрышей
- Сессии игроков
- Прогресс-бар загрузки
- Адаптивный UI
- Подсветка выигрышных комбинаций

## Управление

- **SPIN** или **Пробел** — вращение
- **+/-** — изменение ставки

## API

### POST /api/game/init
Создаёт сессию, возвращает баланс и настройки.

### POST /api/game/spin
```json
{ "sessionId": "...", "bet": 100 }
```
Возвращает:
```json
{
  "grid": [["crown","heart","diamond"], ...],
  "wins": [{ "line": 0, "symbol": "crown", "count": 3, "amount": 250 }],
  "totalWin": 250,
  "balance": 10150
}
```
