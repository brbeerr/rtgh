# MeshVPN - Виртуальная сеть для мобильных

Аналог Radmin VPN для телефонов. Создавайте приватные комнаты, общайтесь в чате, видите кто онлайн.

## Возможности

- Создание приватных комнат с уникальным 8-символьным ключом
- Вход по ключу доступа
- Чат в реальном времени (SSE)
- Список участников с виртуальными IP
- 7 бесплатных серверов (EU, US, Asia, RU)
- Мобильный адаптивный интерфейс
- Без зависимостей (чистый Node.js)

## Запуск

```bash
cd mesh-vpn
node server.js
```

Открыть: http://localhost:3000

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | /api/servers | Список серверов |
| POST | /api/rooms/create | Создать комнату |
| POST | /api/rooms/join | Войти по ключу |
| POST | /api/rooms/message | Отправить сообщение |
| POST | /api/rooms/leave | Выйти из комнаты |
| GET | /api/rooms/events | SSE подключение |
| GET | /api/rooms/info | Инфо о комнате |
